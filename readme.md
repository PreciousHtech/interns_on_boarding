# 🧑‍💻 Developer Onboarding & Environment Setup Guide

Welcome to the team! 🎉  
This guide will walk you through setting up your development environment so you can start contributing to our projects smoothly.

---

## 📋 Overview
Follow each step carefully and confirm completion once done.  
If you run into any issues, contact your team lead for assistance.

---

## 🧠 Prerequisites
Before you begin, ensure you have:
- A stable internet connection
- At least **8GB RAM**
- Windows 10/11, macOS, or Linux
- Basic familiarity with using a terminal/command prompt

---

## 1️⃣ Create Required Accounts

### 🔹 GitHub
1. Visit [https://github.com](https://github.com)
2. Create an account using your professional or school email
3. Verify your email address
4. Share your **GitHub username** with your team lead

---

## 2️⃣ Install Essential Tools

### 🧰 1. Git
- **Download:** [https://git-scm.com/downloads](https://git-scm.com/downloads)
- After installation, verify by running:
  ```bash
  git --version
  ```
- **Set up your Git configuration:**
  ```bash
  git config --global user.name "Your Name"
  git config --global user.email "your@email.com"
  ```

---

### 💻 2. Visual Studio Code (VS Code)
- **Download:** [https://code.visualstudio.com](https://code.visualstudio.com)
- **Recommended Extensions:**
    - Prettier – Code Formatter
    - ESLint
    - GitLens
    - Live Server
    - Auto Rename Tag
    - Bracket Pair Colorization
    - Error Lens by Alexander
    - Windsurf Plugin (formerly Codeium): AI Coding
    - REST Client (for testing APIs)

---

### 🟨 3. Node.js & npm
- **Download:** [https://nodejs.org/](https://nodejs.org/) (Choose the **LTS version**)
- **Verify installation:**
  ```bash
  node -v
  npm -v
  ```
- **Optional:** Install Yarn for dependency management
  ```bash
  npm install --global yarn
  ```

---

### 🌐 4. Web Development Basics
You should have a foundational understanding of:
- **HTML** – structure of web pages
- **CSS** – styling web pages
- **JavaScript (ES6+)** – interactivity and logic

If you’re new, go through these crash courses:
- [HTML & CSS by MDN](https://developer.mozilla.org/en-US/docs/Learn/Getting_started_with_the_web)
- [JavaScript Basics](https://javascript.info/)

---

## 3️⃣ Recommended Developer Tools

### 🔧 Terminal / Command Line
- **Windows:** Use *Git Bash* or *Windows Terminal*
- **macOS/Linux:** Use your built-in terminal

### 🗂 Version Control
- **Optional GUI:** [GitHub Desktop](https://desktop.github.com/)

### 🌍 Browser
- Install **Google Chrome** or **Microsoft Edge**
- Optional: Add **React/Redux DevTools** extension for debugging frontend projects

## ✅ Next Steps
Once you’ve completed the setup:
1. Send your **GitHub username** to your team lead.
2. Take a screenshot showing:
    - Terminal output of `node -v` and `git --version`
    - VS Code open with a cloned repository
3. Your team lead will grant you access to your first project repository.
